## 正文

### 背景

目前账号页只读取「我的 → 观看记录」，收藏功能仅限「收藏到本机」——数据存在本机，与红果 App 里的收藏完全无关。用户如果已在红果 App 内收藏了短剧，无法在本应用查看，只能靠本机收藏重复维护一份。

本 PR 补上官方收藏夹的读取能力：直接读账号云端书架，与观看记录并列展示。

### 实现

复用现有账号基础设施（扫码登录态、设备身份、账号签名），新增一个只读接口：

| 项    | 值                                                          |
| ---- | ---------------------------------------------------------- |
| 接口   | `GET /reading/bookapi/bookshelf/video/info/v1/`            |
| host | `api5-normal-sinfonlinea.fqnovel.com`（账号类接口用 `a`，播放类用 `b`） |
| aid  | `8662`                                                     |
| 参数   | 无                                                          |

响应结构为 `data.video_shelf_info[]`，剧集信息位于嵌套的 `video_data`（`series_id` / `title` / `cover_url` / `thumb_url` / `episode_cnt`），外层另带 `series_title` / `series_cover_url` / `series_intro` / `collect_time`。

与观看历史共用同一套登录态与设备身份，不需要额外登录流程。

### 解析策略

官方返回的字段名在不同版本间有出入，解析器按「外层优先、内层兜底」逐个字段尝试：

- **剧号**：`video_data.series_id` → `series_id` → `book_id`
- **剧名**：`series_title` → `video_data.title` → `book_name`
- **封面**：`series_cover_url` → `video_data.cover` / `cover_url` / `thumb_url` → `thumb_url`
- **集数**：`video_data.episode_cnt` → `video_data.episode_count` → `episode_cnt`

另有几处刻意的处理：

- **空书架与格式变化要分清**：官方用 `null` 表示空书架，属正常状态，返回空列表；但如果 `video_shelf_info` 字段缺失、或有条目却一条都解析不出来，则如实报错，而不是伪装成「没有收藏」——否则用户会被一个空列表误导。
- **收藏时间有两种单位**：官方有时给秒、有时给毫秒，统一归一为毫秒。按固定位数阈值判断即可覆盖（10 位以内是秒，更长的是毫秒）。
- **剧号去重**：同一剧收藏多次只保留一条。

### 交互

- 账号页「官方收藏夹」分区与「观看记录」**并列**，两者独立，互不影响。
- 显示剧名、封面、集数、简介与收藏时间，支持按剧名搜索。
- 点击收藏项会拉取该剧分集并进入播放页；本地没有档案时自动补齐分集列表。
- 登录成功、退出账号、账号状态变化时同步刷新收藏列表；收藏为空时给出明确提示而不是空白页。

### 只读说明

本 PR **只做读取**，不会在红果账号侧增删收藏，收藏内容始终留在官方账号，本机不留副本。

增删收藏的接口是 `bookshelf/video/update/v1/`，本次**刻意未**放行。若后续需要，可单独提 PR 讨论。

### 与既有功能的关系

「官方收藏夹」（云端）和「收藏到本机」（本机存储）是两套独立数据，界面上分开呈现，不做自动同步。本机的「收藏到本机」仍按原样工作。

- 空书架（`null` 与 `[]`）返回空列表；结构缺失 / 解析不出时报错
- 剧号格式校验与去重

完整 `npm test` 通过。

### 未验证项与限制

- 收藏接口的返回结构由公开实现交叉验证得到，**未在本 PR 中做真实账号的端到端联调**——账号凭据与真实收藏数据未纳入仓库与测试。
- 官方接口为非公开接口，可能随官方调整而变化。解析器对字段缺失做了显式报错处理，结构变化时会如实告知用户，不会静默显示为空列表。
- 未实现收藏的增删改。
- 未实现收藏的预约 / 追更列表（官方有 `user/subscribe/list` 接口），本次范围仅限收藏。

### 兼容性

- 未登录时返回 `signedIn: false`，UI 显示为空，不报错。
- 不涉及存储格式变更，不影响已有账号会话与本地记录。
- 新增 IPC 均为增量，现有调用方无需改动。
